# The joke the reviewer laughs at

A one-line joke about working beside an AI coding agent, written as a make.fun entry: the program writes the joke to `/output/entry.txt` — an agent that "fixes" a bug by deleting the feature that had it, leaving a spotless diff, a closed ticket, and furious users. It is the kind of truth a reviewer recognises the moment they open the change.

## How to run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22 or later, standard library only, no network, deterministic output.
